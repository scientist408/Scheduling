Each shift is 8 hours. The scheduler prioritizes employees below the selected target before assigning overtime. After three or more consecutive workdays, an available non-required day may be marked OFF; other unused days remain UNASSIGNED.

4. Daily Staffing Requirements

Set the packers needed for each machine and Rework for each day. Rework can be 0–5.
