Production Employee Scheduler

Custom Machines • Daily Packer Requirements • Skills • R/OFF • Other Plant • Rework • 5/6/7-Day Scheduling

1. Paste Employee List

Paste Employee Name and Employee ID from Excel. Use ALL for all machines and Rework, or enter skills such as 1B,2B,5B,REWORK.

2. Machine Setup

Create machines as prefix format such as B1–B13, suffix format such as 1B–8B, or type any custom list.

Examples: Prefix B + 1–13 creates B1 through B13. Suffix B + 1–8 creates 1B through 8B.

3. Schedule Settings

Other Plant days count as 8 hours and toward the selected weekly workday limit.

4. Daily Staffing Requirements

Enter the number of packers required for each machine on each day. For example, set Monday 1B to 2 and Tuesday 1B to 1.
