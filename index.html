3. Schedule Settings

Each shift is 8 hours. The selected hours are treated as the minimum each available employee should receive. Employees below the minimum are prioritized before overtime. Local machine and Rework assignments are used first; EBM2 or Tubing are used only when needed to reach the minimum. Remaining nonworking days are distributed between OFF and UNASSIGNED, and every UNASSIGNED cell keeps its dropdown.

4. Daily Staffing Requirements

Set the packers needed for each machine and Rework for each day. Rework can be 0–5.

5. Employee Skills
